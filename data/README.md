# data/ — jeux de test uniquement

Ce dossier ne doit contenir **que des données DICOM anonymisées ou synthétiques**, jamais de données patient réelles, à aucun stade du projet (POC, développement, démonstration).

Le `.gitignore` du projet ignore le contenu de ce dossier par défaut (sauf ce README) — pensez à ajouter explicitement vos fichiers de test si vous voulez les versionner, en vérifiant au préalable qu'ils sont bien anonymisés/synthétiques.
