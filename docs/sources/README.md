# Sources historiques

Ce dossier conserve les documents sources du projet.

`dossier-projet-original.md` reprend le contenu du dossier historique préparé pour une présentation bailleur. Le fichier portait auparavant l'extension `.docx`, mais son contenu est du texte UTF-8. Il a donc été renommé avec une extension Markdown cohérente, sans fabriquer de document Word.
