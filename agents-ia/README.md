# Agents IA — vue d'ensemble

Une fiche par agent, classée par horizon de mise en œuvre. Chaque fiche suit le même format : objectif, entrées, sorties, garde-fous, statut.

**Règle transversale (voir CLAUDE.md/AGENTS.md)** : aucun agent IA ne produit de diagnostic final opposable. Toute sortie touchant à l'interprétation d'image ou à la décision clinique est une suggestion soumise à validation humaine par un radiologue.
